?
常见问题
❓ Windows Defender 拦截怎么办？
PyInstaller 打包的程序可能被误报为病毒。解决方法：右键文件 → 属性 → 勾选"解除锁定" → 应用。
❓ 防火墙提示怎么处理？
首次运行时 Windows 防火墙会弹出提示，选择"允许访问"并勾选"专用网络"和"公用网络"。
❓ 打包失败怎么办？
点击工作流运行记录查看详细错误日志，通常是在 "Build EXE with PyInstaller" 步骤查看。
❓ 如何重新打包？
修改代码后推送新的 commit，或者在 Actions 页面点击 "Run workflow" 按钮手动触发。
